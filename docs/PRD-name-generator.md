# PRD: Генератор имён под сеттинг

## Problem Statement

При подготовке личных RPG-кампаний, историй и миров нужно быстро находить имена персонажей, звучащие уместно для конкретного сеттинга (стимпанк, викторианское фэнтези, sci-fi и т.д.). Ручной поиск подходящих имён в интернете занимает много времени и редко даёт результат, стилистически привязанный именно к нужной эпохе/культуре/вселенной. Нужен инструмент, который генерирует набор имён под выбранный сеттинг за секунды.

## Goals

1. Сгенерировать батч имён, звучащих уместно для выбранного сеттинга, за один клик и меньше чем за секунду (локальные вычисления, без сети).
2. Покрыть 3 сеттинга на старте, звучащих узнаваемо различно друг от друга.
3. Поддержать фильтр по полу имени (муж./жен./нейтральное) там, где это применимо к сеттингу.
4. Сократить время подбора имени с «минут гугления» до «секунд генерации».
5. Дать возможность быстро перегенерировать список, если ни одно имя не подошло.

## Non-Goals

- **Аккаунты, бэкенд, облачное хранение** — инструмент личный, локальный/клиентский; многопользовательский режим не нужен.
- **Сохранение избранного между сессиями** — пользователь явно отказался; достаточно списка на экране в моменте генерации.
- **Генерация через LLM/API в v1** — начинаем с локальных шаблонов+слогов; гибрид с LLM — возможное будущее расширение, не v1.
- **Фамилии, топонимы, названия фракций/организаций** — в v1 только личные имена персонажей; остальные типы — будущее расширение.
- **Точные имена из конкретных копирайтных вселенных** (Толкин, Star Wars и т.п.) — генерация «в стиле», не воспроизведение существующих защищённых имён, чтобы избежать вопросов авторского права.

## User Stories

- Как пользователь, я хочу выбрать сеттинг (например, «Стимпанк») из списка, чтобы получить имена, звучащие уместно для этого мира.
- Как пользователь, я хочу указать пол имени (муж./жен./нейтральное), чтобы сгенерированные варианты подходили под конкретного персонажа.
- Как пользователь, я хочу задать количество вариантов за раз, чтобы выбирать из нескольких, а не генерировать по одному.
- Как пользователь, я хочу одним кликом перегенерировать список, если ни один вариант не подошёл, без повторной настройки фильтров.
- Как пользователь, я хочу, чтобы имена разных сеттингов звучали различимо (Викторианское фэнтези ≠ Киберпанк), чтобы не терялось ощущение мира.

## Requirements

### Must-Have (P0)

1. **3 сеттинга на старте**: Историческое (реальные эпохи/культуры), Фэнтези, Sci-Fi / космоопера / киберпанк.
   - «Историческое» в v1 объединяет 4 под-периода/региона: Западная Европа 1200–1600, Восточная Европа 1200–1600, США XX век, Европа XX век.
   - Acceptance criteria:
     - [ ] Пользователь может выбрать один из 3 сеттингов из списка/выпадающего меню
     - [ ] Каждый сеттинг имеет собственный набор шаблонов/слогов, отличимый на слух от других
     - [ ] Датасет «Исторического» покрывает все 4 под-периода/региона (Зап. Европа 1200–1600, Вост. Европа 1200–1600, США XX век, Европа XX век)
2. **Локальная генерация по шаблонам и слогам**, без обращения к внешним API.
   - Acceptance criteria:
     - [ ] Генерация не требует сетевого запроса
     - [ ] Результат появляется практически мгновенно (< 5 сек)
     - [ ] Повторная генерация с теми же настройками даёт новый набор имён (не детерминированный повтор)
3. **Фильтр по полу**: муж. / жен. / нейтральное.
   - Acceptance criteria:
     - [ ] Пользователь может выбрать пол перед генерацией
     - [ ] Для сеттингов, где применимо, имена соответствуют выбранному полу
4. **Количество вариантов за раз** (настраиваемое, например 1–10).
   - Acceptance criteria:
     - [ ] Пользователь может задать число генерируемых имён
     - [ ] Список результатов содержит ровно запрошенное количество
5. **Один экран**: выбор сеттинга → пол → количество → кнопка «Сгенерировать» → список результатов → кнопка «Ещё».
   - Acceptance criteria:
     - [ ] Все элементы управления доступны без переходов между страницами
     - [ ] Кнопка регенерации сохраняет текущие настройки фильтров

### Nice-to-Have (P1)

- Копирование имени / всего списка в буфer обмена
- Под-стили внутри категории: для «Исторического» — выбор конкретного под-периода/региона (Зап. Европа 1200–1600 / Вост. Европа 1200–1600 / США XX век / Европа XX век) или их микс, а не только общий пул


### Future Considerations (P2)

- Гибридная генерация через LLM API для более разнообразных/редких вариантов
- Дополнительные типы имён: фамилии, топонимы, названия фракций/организаций
- Сохранение избранных имён (потребует localStorage или аккаунт — сейчас осознанно не нужно)
- Расширение списка сеттингов по мере новых потребностей
- Псевдо-этимология / «значение» сгенерированного имени
- Экспорт списка (копирование/скачивание файла)

## Success Metrics

Поскольку это личный инструмент без внешних пользователей, метрики — по факту личного использования, не аналитика:

**Leading**
- Время от открытия инструмента до получения пригодного имени ≤ 15 секунд
- В батче из ~10 имён минимум 3 ощущаются «пригодными» (субъективная самопроверка)

**Lagging**
- Инструмент реально используется в проектах спустя 1 месяц после первой версии (а не заброшен)
- Со временем добавляются новые сеттинги под конкретные нужды — признак, что инструмент прижился

## Open Questions

- **(контент, не блокирует старт)** Конкретные наборы слогов/шаблонов по каждому сеттингу/под-периоду — это отдельная работа по наполнению данных, а не архитектурное решение.

## Timeline Considerations

Без дедлайна — проект для себя, в свободном темпе. Явного поэтапного релиза не требуется, но естественная фазировка:
- **Фаза 1**: P0 целиком (все 3 сеттинга, локальная генерация, пол, количество, один экран)
- **Фаза 2**: P1 по мере желания (копирование, под-стили, темизация)
- **Фаза 3+**: P2 — только если появится реальная потребность (LLM-гибрид, доп. типы имён, избранное)
