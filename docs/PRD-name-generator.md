# PRD: Генератор имён под сеттинг

## Problem Statement

При подготовке личных RPG-кампаний, историй и миров нужно быстро находить имена персонажей, звучащие уместно для конкретного сеттинга (стимпанк, викторианское фэнтези, sci-fi и т.д.). Ручной поиск подходящих имён в интернете занимает много времени и редко даёт результат, стилистически привязанный именно к нужной эпохе/культуре/вселенной. Нужен инструмент, который генерирует набор имён под выбранный сеттинг за секунды.

## Goals

1. Сгенерировать батч имён, звучащих уместно для выбранного сеттинга, за один клик и меньше чем за секунду (локальные вычисления, без сети).
2. Покрыть 2 сеттинга, звучащих узнаваемо различно друг от друга.
3. Поддержать фильтр по полу имени (муж./жен./нейтральное) там, где это применимо к сеттингу.
4. Сократить время подбора имени с «минут гугления» до «секунд генерации».
5. Дать возможность быстро перегенерировать список, если ни одно имя не подошло.

## Non-Goals

- **Аккаунты, бэкенд, облачное хранение** — инструмент личный, локальный/клиентский; многопользовательский режим не нужен.
- **Сохранение избранного между сессиями** — пользователь явно отказался; достаточно списка на экране в моменте генерации.
- **Генерация через LLM/API в v1** — начинаем с локальных шаблонов+слогов; гибрид с LLM — возможное будущее расширение, не v1.
- ~~Фамилии~~ — **реализовано для Realistic и Fantasy**: оба сеттинга теперь всегда генерируют «Имя Фамилия». Realistic — реальные CC0-фамилии по региону имени. Fantasy — оригинальные выдуманные имена/фамилии из [little-namegenerator](../src/lib/names/data-import/README.md) (MIT), смешанные с собственной слоговой генерацией. Сеттинг Sci-Fi удалён (см. Non-Goals) — фамилий у него так и не появилось.
- **Топонимы, названия фракций/организаций** — не в v1; будущее расширение.
- **Точные имена из конкретных копирайтных вселенных** (Толкин, Star Wars и т.п.) — генерация «в стиле», не воспроизведение существующих защищённых имён, чтобы избежать вопросов авторского права.
- **Sci-Fi / космоопера / киберпанк** — сеттинг **удалён** (2026-11-20). Был слоговой генерацией на ~16 строках данных, без фамилий, титулов и прозвищ; подходящей открытой базы sci-fi-имён не нашлось (все найденные — либо игрушечные скрипты, либо производные от копирайтных вселенных вроде No Man's Sky/StarCraft). Фокус сознательно сужен до двух живых сеттингов — Realistic и Fantasy. Удаление чистое, вернуть можно из истории git.

## User Stories

- Как пользователь, я хочу выбрать сеттинг (например, «Стимпанк») из списка, чтобы получить имена, звучащие уместно для этого мира.
- Как пользователь, я хочу указать пол имени (муж./жен./нейтральное), чтобы сгенерированные варианты подходили под конкретного персонажа.
- Как пользователь, я хочу задать количество вариантов за раз, чтобы выбирать из нескольких, а не генерировать по одному.
- Как пользователь, я хочу одним кликом перегенерировать список, если ни один вариант не подошёл, без повторной настройки фильтров.
- Как пользователь, я хочу, чтобы имена разных сеттингов звучали различимо (Фэнтези ≠ Реалистичное), чтобы не терялось ощущение мира.

## Requirements

### Must-Have (P0)

1. **2 сеттинга**: Реалистичное (реальные эпохи/культуры/современность) и Фэнтези. Изначально планировался третий — Sci-Fi / космоопера / киберпанк — но он **удалён**, см. Non-Goals.
   - «Реалистичное» (изначально называлось «Историческое» — переименовано, так как теперь включает и современные/XXI века имена, не только исторические) в v1 объединяет 14 под-периодов по 8 регионам: Западная Европа (1200–1600, XX век, XXI век), Восточная Европа (1200–1600, XX век, XXI век), США (XX век, XXI век), Латинская Америка (XX век, XXI век), Средняя Азия (XXI век), Индия (XXI век), Япония (XXI век), Китай (XXI век).
   - Данные для XXI века — из реального CC0-датасета популярных имён по странам ([src/lib/names/data-import/](../src/lib/names/data-import/)), не выдуманы вручную.
   - Пользователь может дополнительно сузить выбор через селекты «Регион» и «Век» (реализовано, см. P1 ниже — фактически уже P0-функциональность, а не отложенная).
   - **Периодизация пересмотрена** — см. [Историческая периодизация европейских имён](#историческая-периодизация-европейских-имён). Сетка «регион × век» заменяется плоским списком периодов, границы которых совпадают со сменой именного фонда. **Начато:** период `1200_1600` переименован в `1300_1550` и ячейка «Западная Европа» наполнена (64 мужских / 50 женских имён + свой пул фамилий периода). Остальные под-периоды пока работают по-старому.
   - Acceptance criteria:
     - [ ] Пользователь может выбрать один из 2 сеттингов из списка/выпадающего меню
     - [ ] Каждый сеттинг имеет собственный набор шаблонов/слогов, отличимый на слух от других
     - [ ] Датасет «Реалистичного» покрывает все 14 под-периодов/регионов
2. **Локальная генерация по шаблонам и слогам**, без обращения к внешним API.
   - Acceptance criteria:
     - [ ] Генерация не требует сетевого запроса
     - [ ] Результат появляется практически мгновенно (< 5 сек)
     - [ ] Повторная генерация с теми же настройками даёт новый набор имён (не детерминированный повтор)
3. **Фильтр по полу**: муж. / жен. / нейтральное.
   - Acceptance criteria:
     - [ ] Пользователь может выбрать пол перед генерацией
     - [ ] Для сеттингов, где применимо, имена соответствуют выбранному полу
4. **Количество вариантов за раз** (настраиваемое, например 1–10).
   - Acceptance criteria:
     - [ ] Пользователь может задать число генерируемых имён
     - [ ] Список результатов содержит ровно запрошенное количество
5. **Один экран**: выбор сеттинга → пол → количество → кнопка «Сгенерировать» → список результатов → кнопка «Ещё».
   - Acceptance criteria:
     - [ ] Все элементы управления доступны без переходов между страницами
     - [ ] Кнопка регенерации сохраняет текущие настройки фильтров

### Nice-to-Have (P1)

- Копирование имени / всего списка в буфer обмена
- ~~Прозвища/титулы~~ — **реализовано**: два независимых чекбокса «Include title» и «Include nickname» для Fantasy и Realistic. - ~~Под-стили внутри категории: выбор конкретного под-периода/региона~~ — **реализовано** в P0 (селекты «Регион» + «Век» на экране «Реалистичного»)
- ~~Реальные (не слоговые) имена для Фэнтези, смешанные автоматически~~ — **реализовано**: 40% шанс на реальное историческое/мифологическое имя (Alaric, Freya, Guinevere и т.п. — только public domain, без персонажей конкретных копирайтных вселенных), 60% — слоговая генерация

## Историческая периодизация европейских имён

**Решение от 2026-11-20.** Деление «Реалистичного» на периоды строится не как декартово произведение «регион × век», а как плоский список периодов, границы которых совпадают со сменой именного фонда. Матрица вида «7 регионов × 9 периодов» (~63 ячейки) отвергнута: большинство её ячеек либо не существует исторически («Америка до открытия, XIX век»), либо не имеет источников данных приемлемого качества.

### Откуда взяты границы

Не из общей логики, а из того, как режут корпуса сами практики и исследователи:

| Источник | Как делит |
|---|---|
| [Medieval Names Archive](https://s-gabriel.org/names/english.shtml), английский раздел | Old English → от Завоевания до 1300 → 1300–1450 → 1450–1600 → нач. XVII в. |
| Там же, индекс по Reaney | до 1250 / 1250–1450 / после 1450 |
| [Medieval Names Archive](https://s-gabriel.org/names/french.shtml), французский раздел | Основное деление **не по дате, а по языку**: Frankish vs French; слом ок. XI–XII в. |
| [DMNES](https://dmnes.org/about) | Окно словаря целиком: 500–1600 |
| [Kohlheim & Kohlheim, Onoma 55](https://onomajournal.org/wp-content/uploads/2021/08/Onoma-55-1.05-Kohlheim-Kohlheim-final-web-August.pdf) | Поворот XII века: религиозно мотивированные имена + одновременный рост описательных байнеймов *(по реферату; полный текст PDF прочитать не удалось)* |
| [Uckelman, англ. имена 1550–1600](https://sluckelman.webspace.durham.ac.uk/wp-content/uploads/sites/218/2021/04/snsbi2018.pdf) | Сдвиг к ветхозаветным именам («Hebrew invasion») |

Сходятся на границах **~1100, ~1250–1300, ~1450, ~1550–1600**. Ни 1200, ни 1700 в этом списке нет — нынешний период `1200_1600` сидит поперёк двух границ сразу.

### Принятая сетка

| Период | Именной фонд | Формула имени |
|---|---|---|
| **600–1100** | германский / славянский / докрещенский (Sigebert, Æthelred, Gunnhildr) | имя + (опц.) байнейм. **Фамилий нет** |
| **1100–1300** | переход: христианские имена вытесняют германские | имя + байнейм (патроним / топоним / ремесло), **ещё не наследственный** |
| **1300–1550** | насыщенный фонд святых имён (John, William, Alice, Agnes) | имя + наследственная фамилия + (опц.) прозвище |
| **1550–1800** | конфессиональный раскол: ВЗ-имена и virtue-имена у протестантов, святые у католиков | имя + фамилия + (опц.) титул |

Плюс существующие XX и XXI век; XIX век — опционально.

**Почему 600–1100 и 1100–1300 нельзя склеивать.** Это единственная граница, которую стирать нельзя: до ~1100 фонд германский (Sigebert, Hrodland, Gunnhildr), после — христианский (John, William, Alice). Это не оттенок звучания, а полная замена фонда. Французский раздел Medieval Names Archive именно поэтому делит корпуса на Frankish/French, а не по векам. Один период «VI–XIII» выдавал бы Æthelred и John как равновероятные — разброс в 500 лет.

**Почему 1300–1550 можно одним куском.** Слои 1300–1450 и 1450–1600 у архива — соседние ломти одного и того же фонда святых имён; меняется орфография записи, а не состав.

### Следствия для движка

1. **Формула имени задаётся периодом, а не глобальными чекбоксами.** Текущая схема «имя + фамилия + опц. титул + опц. прозвище» исторически верна только для 1550–1800 и позже. До ~1300 фамилии нет — её роль играет байнейм (патроним, топоним, ремесло, прозвище); наследственные фамилии расходятся по Европе с XI–XV вв. неравномерно и у крестьянства запаздывают. Вне Европы: Япония — фамилии простолюдинам по закону 1875 г., Турция — 1934 г., Скандинавия — патронимы до XIX–XX вв. (Исландия по сей день).
2. **Объём данных на ячейку мал и ограничен.** По налоговым спискам 1377–1381 ([Редмондс, 10 графств](https://www.behindthename.com/top/lists/england-medieval/1377)): John 35.32%, William 18.34%, Thomas 9.45%, Richard 8.31%, Robert 7.41% — три имени покрывают ~63% мужчин ([CAMPOP](https://www.campop.geog.cam.ac.uk/blog/2025/07/03/whats-in-a-name/) по тому же Редмондсу даёт топ-3 ≈ 53%, топ-5 ≈ 79% — расхождение методик, направление однозначно). Полный список — 50 мужских + 50 женских имён, покрывающих практически всё население. «Полная» позднесредневековая английская ячейка — это ~100 имён, и она **исчерпывающая**, а не выборочная.
3. **Равновероятный выбор оставляем сознательно.** `pickRandom` делает Nicholas (1.63%) равновероятным с John (35%) — исторически неверно, но для мастера полезно: нужны 10 разных имён, а не три Джона. Поэтому честная формулировка — «имена, существовавшие в этот период», а не «имена в исторических пропорциях».
4. **`neutral` для доXIX-вековых периодов отключается.** Унисекс-имён в современном смысле в этих фондах не было; нынешние 4 имени на период подобраны вручную и для исторических периодов являются выдумкой.

### Лицензии: имена свободны, списки — нет

Отдельное имя авторским правом не охраняется. Но проекту нужны **списки**, а права живут именно в них — и репозиторий публичный, значит это redistribution.

| Источник | Что даёт | Лицензия |
|---|---|---|
| [DMNES](https://dmnes.org/) | 500–1600; у каждой цитаты год, страна, язык, написание как в документе; пол на уровне статьи; XML в git-репозитории | **Лицензии нет.** «© 2015–2023 The Editors». Репозиторий не опубликован, дампа и API нет |
| [Medieval Names Archive](https://s-gabriel.org/names/) | Готовые корпуса по периодам и регионам | Лицензии нет; «Copyright on individual articles belongs to their authors». Любительский архив SCA, не научный |
| [Behind the Name](https://www.behindthename.com/info/terms) | Список 1377–1381 с процентами, Италия 1427 | **Прямо запрещено**: «You may not redistribute content from this site unless you obtain written permission in advance» |

Варианты: (а) запросить разрешение у Sara L. Uckelman (Durham University) на использование DMNES в личном некоммерческом инструменте; (б) идти в первоисточники public domain — налоговые списки 1377–1381, флорентийский катасто 1427 (опубликован как исследовательский датасет Herlihy & Klapisch-Zuber — лицензию надо проверить).

**Правило:** ни одна новая ячейка не попадает в репозиторий без указанного источника и его лицензии в [data-import/README.md](../src/lib/names/data-import/README.md).

### Порядок реализации

Начинать с **1300–1550**: для него есть исчерпывающий частотный материал, он покрывает нынешний период `1200_1600`, и формула «имя + фамилия + прозвище» работает без рефактора движка — то есть даёт замер реальной цены ячейки на самом дешёвом варианте. Затем **600–1100**, где нужна новая формула без фамилий. Остальные периоды — по результатам замера.

## Success Metrics

Поскольку это личный инструмент без внешних пользователей, метрики — по факту личного использования, не аналитика:

**Leading**
- Время от открытия инструмента до получения пригодного имени ≤ 15 секунд
- В батче из ~10 имён минимум 3 ощущаются «пригодными» (субъективная самопроверка)

**Lagging**
- Инструмент реально используется в проектах спустя 1 месяц после первой версии (а не заброшен)
- Со временем добавляются новые сеттинги под конкретные нужды — признак, что инструмент прижился

## Open Questions

- **(контент, не блокирует старт)** Конкретные наборы слогов/шаблонов по каждому сеттингу/под-периоду — это отдельная работа по наполнению данных, а не архитектурное решение.
- **(данные)** Источник полноценной базы имён по культурам: найден [sigpwned/popular-names-by-country-dataset](https://github.com/sigpwned/popular-names-by-country-dataset) (CC0, 106 стран, включая всю Латинскую Америку/Европу/США) — но **без разметки по полу**, что критично для P0-фильтра. Решение: импортировать сырые данные без пола, разметку по полу сделать отдельным проходом позже.
- **(данные, решено частично)** Источники исторических имён до 1600 проверены — см. [Историческая периодизация европейских имён](#историческая-периодизация-европейских-имён). Главное ограничение оказалось не в копирайте на сами имена (отдельное имя не охраняется), а в том, что лучшие по качеству корпуса — DMNES, Medieval Names Archive, Behind the Name — **не лицензированы для повторного использования**, а репозиторий публичный. Открыто: запрашивать ли разрешение у DMNES (Sara L. Uckelman, Durham) или ограничиться первоисточниками public domain.

## Timeline Considerations

Без дедлайна — проект для себя, в свободном темпе. Явного поэтапного релиза не требуется, но естественная фазировка:
- **Фаза 1**: P0 целиком (оба сеттинга, локальная генерация, пол, количество, один экран)
- **Фаза 2**: P1 по мере желания (копирование, под-стили, темизация)
- **Фаза 3+**: P2 — только если появится реальная потребность (LLM-гибрид, доп. типы имён, избранное)
