# Импортированные имена — теперь подключены как «XXI век»

## Что это

Сырые данные из [sigpwned/popular-names-by-country-dataset](https://github.com/sigpwned/popular-names-by-country-dataset) — популярные имена по странам, источник в основном официальная статистика (данные о рождаемости и т.п.) за разные годы (в основном 2010-е–2018).

- **Лицензия**: CC0 (public domain) — можно использовать без ограничений и без указания авторства.
- **Файл**: [imported-forenames.json](imported-forenames.json)
- **Формат**: `{ [регион]: { F: [{ country, name }], M: [{ country, name }] } }`, регион — один из наших `RealisticRegion`.
- **Латиница**: используется колонка `Romanized Name` из исходного CSV, а не `Localized Name` — для Японии/Китая/России и т.п. это латинская транслитерация (Aoi, Ruòxī), а не иероглифы/кириллица. Для японского один иероглиф может иметь несколько вариантов чтения — в датасете это отдельные строки, поэтому у Японии больше вариантов, чем уникальных «оригинальных» имён.

## Статус: подключено

Раньше это было staging-данными без подключения — несоответствие эпохи (2010-е имена vs «винтажный» XX век в остальных периодах) решили не смешиванием, а **отдельным периодом «XXI век»** для каждого региона (`{region}_21st_century` в `realisticDataset`, см. [realistic.ts](../datasets/realistic.ts)). Файл `imported-forenames.json` импортируется туда напрямую и служит единственным источником для мужских/женских имён этих периодов — дублирования данных нет.

## Что осталось не из датасета

У источника нет нейтральных/гендерно-неопределённых имён (только F/M) — для каждого нового периода `neutral` подобран вручную (по 4 имени), не из датасета. Для Западной/Восточной Европы, США, Латинской Америки — уверенность высокая (знакомые культуры). **Для Средней Азии и Индии уверенность ниже** — список отражает моё лучшее приближение (например, Simran/Amrit как пенджабские/сикхские имена, которые действительно используются для обоих полов), стоит перепроверить, если это важно для реального использования.

## Ячейка «Западная Европа, 1300–1550» — ручное курирование

**Источник: ручное курирование. Лицензия: нет ограничений — списки составлены с нуля.**

### Почему не датасет

Открытого датасета средневековых имён не существует. Проверено:

| Источник | Что даёт | Почему нельзя |
|---|---|---|
| [DMNES](https://dmnes.org/) | 500–1600, у каждой цитаты год, страна, язык, написание | Лицензии нет («© 2015–2023 The Editors»), публичного репозитория и дампа нет. Запрос на доступ к git-репозиторию в рассылке 2015 года остался без ответа |
| [Medieval Names Archive](https://s-gabriel.org/names/) | Готовые корпуса по периодам | Лицензии нет, «Copyright on individual articles belongs to their authors» |
| [Behind the Name](https://www.behindthename.com/info/terms) | Список 1377–1381 с частотами | Прямой запрет: «You may not redistribute content from this site» |
| CC0-датасеты на GitHub | [sigpwned](https://github.com/sigpwned/popular-names-by-country-dataset) и аналоги | Только современные имена (статистика 2010-х), исторических нет |

Поэтому списки для этой ячейки собраны вручную. Отдельное имя авторским правом не охраняется — ограничения касаются чужих **подборок**, а ни одна чужая подборка сюда не копировалась.

### Что в ячейке

- **Имена** — [realistic.ts](../datasets/realistic.ts), `western_europe_1300_1550`: 64 мужских, 50 женских. Позднесредневековый христианский именной фонд, смесь Англии, Франции, германских земель, Италии и Иберии.
- **Фамилии** — [realisticPeriodSurnames.ts](../datasets/realisticPeriodSurnames.ts): 52 фамилии того же периода. Это **переопределение** регионального пула: общий пул по «Западной Европе» взят из современной статистики (2010-е) и для средневековой ячейки не годится — он давал «Guillaume Jensen». Периоды без своей записи по-прежнему используют региональный пул.

Литература для сверки (не источник копирования): George Redmonds, *Christian Names in Local and Family History* (2004); Scott Smith-Bannister, *Names and Naming Patterns in England 1538–1700* (Oxford, 1997); перечисленные выше DMNES и Medieval Names Archive.

### Что в этой ячейке осознанно не сделано

1. ~~«Западная Европа» смешивает пять именных культур~~ — **исправлено**, см. раздел «Разметка по культурам» ниже.
2. **Частоты не учитываются.** В списках 1377–1381 John — примерно треть всех мужчин, но движок выбирает равновероятно. Решение сознательное, см. PRD: мастеру нужны 10 разных имён, а не три Джона.
3. **`neutral` не тронут** — унаследованные 4 имени, не проверены. В средневековой Европе пула имён общего рода не было; PRD предписывает отключить выбор «neutral» на периодах до XIX века, но это отдельное изменение.

## Разметка по культурам

Раньше имя и фамилия выбирались независимо, и генератор выдавал «Niccolò Baker» — итальянское имя с английской фамилией. Причина была не в данных, а в структуре: поле `country`, которое есть в обоих исходных JSON, выбрасывалось при импорте.

Теперь каждое имя несёт свою культуру (`CulturedName` в [types.ts](../types.ts)):

- **импортированные имена** — культура это ISO-код страны прямо из датасета;
- **рукописные ячейки XX века** — размечены теми же ISO-кодами, поэтому пары с региональными пулами фамилий работают бесплатно;
- **1300–1550** — слаги (`england`, `france`, `german`, `italy`, `iberia`), под которые заведены соответствующие блоки в [realisticPeriodSurnames.ts](../datasets/realisticPeriodSurnames.ts);
- **часть имён намеренно без культуры** — пан-испанские имена Латинской Америки XX века и неверифицированные `neutral`-пулы. Привязать их к одной стране значило бы выдумать факт.

### Привязка вероятностная, а не жёсткая

Константа `SAME_CULTURE_SURNAME_CHANCE` в [generateNames.ts](../generateNames.ts) — сейчас **0.7**. В 70% случаев фамилия берётся из культуры имени, в остальных — из широкого пула.

Так сделано сознательно. Жёсткая привязка (1.0) читается достовернее, но заметно режет разнообразие: у некоторых стран в датасете всего десяток фамилий (DE — 10 против 100 у IT), и немецкое имя начало бы ходить по кругу. Для инструмента мастера разнообразие чуть важнее полной достоверности. Константа — это ручка: выше к 1 ради точности, ниже ради разнообразия.

Побочная польза: фамилии стран, у которых в датасете нет имён (CR, CU, DO — 90 штук), остаются достижимыми через эти 30%.

### Наборы стран в двух файлах не совпадают

| Регион | Имена | Фамилии | Расхождение |
|---|---|---|---|
| eastern_europe, usa, japan, china | — | — | совпадают полностью |
| western_europe | 18 стран | 17 | CY: 20 имён, 0 фамилий |
| latin_america | 12 | 10 | пересечение всего 7 |
| central_asia | 3 | 1 | фамилии только у KZ |
| india | 4 | 3 | PK без фамилий; у BD 10 мужских имён и 0 женских |

Поэтому выбор идёт **от имени, а не от культуры**: сперва имя (равновероятно, как и раньше — распределение имён не изменилось), затем фамилия из его культуры. Культуры без фамилий просто уходят в фолбэк, а пустые по полу культуры недостижимы, потому что выбираем из существующих имён.

## Период 600–1100: байнеймы вместо фамилий

До примерно 1300 года в большей части Европы фамилий не было. Второй элемент имени существовал, но это был **байнейм** — чей ты сын, откуда родом или чем известен, — и он умирал вместе с носителем, а не передавался детям.

Поэтому формула имени теперь принадлежит периоду, а не является глобальной настройкой. Период, перечисленный в [realisticBynames.ts](../datasets/realisticBynames.ts), строит байнейм; периоды, которых там нет, берут фамилию как раньше.

### Три вида байнеймов

| Вид | Как строится | Пример |
|---|---|---|
| Патронимический | из мужского имени той же культуры + суффикс или частица | `Hakon Sigurdsson`, `Áed mac Óengus` |
| Топонимический | частица + место | `Wulfric of Hamtun`, `Chlodovech de Neustrie` |
| Описательный | частица + эпитет | `Ottar the Red`, `Charles the Bald` |

**Патронимы умножают, а не складывают.** Они строятся из уже имеющихся имён той же культуры, так что 22 скандинавских имени и одно правило дают 22 байнейма без единой новой строки данных. Это противоположность пулам фамилий, где сколько записали, столько и есть.

### Культуры периода

Четыре, и они намеренно держатся порознь — Æthelred, Harald, Chlodovech и Diarmait принадлежат четырём разным именным мирам, просто оказавшимся по соседству:

- `anglo_saxon` — 24 мужских, 18 женских; топонимы и эпитеты (письменного патронимического показателя в общем ходу не было);
- `norse` — 22 и 16; патроним `-sson` / `-sdottir`, он же господствующая форма, в Исландии живая до сих пор;
- `frankish` — 20 и 15; топонимы и эпитеты Каролингов (Карл Лысый, Людовик Благочестивый);
- `gaelic` — 18 и 14; патронимы `mac` и `ua`.

Итого 84 мужских и 63 женских имени.

### Известное упрощение

Морфология к имени отца не применяется. Настоящий древнескандинавский и древнеирландский склоняли бы его (`Haraldr` → `Haraldsson`, `Niall` → `mac Néill`); здесь имя подставляется как есть. Сознательный размен: полноценная морфология для четырёх языков дороже, чем даёт, а полной достоверности мы и не добиваемся.

## Титулы разбиты по эпохам

Раньше список титулов был один на все периоды, и генератор выдавал «Detective John Smith» для 1400 года. Теперь титулы выбираются по эпохе периода (`era` в `realisticPeriodMeta`):

| Эпоха | Периоды | Титулы |
|---|---|---|
| `early_medieval` | 600–1100 | Ealdorman, Thegn, Jarl, Abbot, Reeve, Skald… |
| `late_medieval` | 1300–1550 | Master, Sir, Friar, Alderman, Sheriff, Squire… |
| `modern` | XX и XXI век | Dr., Professor, Detective, Ambassador… |

Отдельное правило: если байнейм оказался описательным, галочка «Include nickname» ничего не добавляет — иначе выходило бы «Eadric the Red the Wise» с двумя эпитетами подряд.

## Расширение пулов и период 600–1100 по Восточной Европе

Рукописные ячейки держали по 8 имён на пол — в батче из 10 они начинали повторяться. Расширены:

| Ячейка | Было (м/ж) | Стало (м/ж) |
|---|---|---|
| `eastern_europe_1300_1550` | 8 / 8 | 42 / 32 |
| `western_europe_20th_century` | 8 / 8 | 40 / 37 |
| `eastern_europe_20th_century` | 8 / 8 | 40 / 34 |
| `usa_20th_century` | 8 / 8 | 30 / 30 |
| `latin_america_20th_century` | 8 / 8 | 30 / 30 |

Ячейки XX века заодно размечены ISO-кодами стран, так что пары с фамилиями у них теперь работают так же, как у остальных.

Новая ячейка `eastern_europe_600_1100` — 54 мужских и 38 женских имени по четырём культурам (`rus`, `poland`, `bohemia`, `serbia`), это раннеславянский именной фонд из двусоставных основ (slav — слава, mir — мир, volod — власть). Байнеймы: патроним `-ovich` / `-ovna` у восточных славян, `-owic` у поляков, топонимы с частицей `z` («z Krakowa», «z Prahy»).

Проверка на минимальный размер пула вшита в тесты: ни один период не может появиться с выборкой меньше 15 имён на пол. Там же проверяется, что у каждого имени в бесфамильных периодах есть культура — без неё правило байнейма не нашлось бы и имя молча получило бы современную фамилию.
