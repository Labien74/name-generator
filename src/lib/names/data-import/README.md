# Импортированные имена — теперь подключены как «XXI век»

## Что это

Сырые данные из [sigpwned/popular-names-by-country-dataset](https://github.com/sigpwned/popular-names-by-country-dataset) — популярные имена по странам, источник в основном официальная статистика (данные о рождаемости и т.п.) за разные годы (в основном 2010-е–2018).

- **Лицензия**: CC0 (public domain) — можно использовать без ограничений и без указания авторства.
- **Файл**: [imported-forenames.json](imported-forenames.json)
- **Формат**: `{ [регион]: { F: [{ country, name }], M: [{ country, name }] } }`, регион — один из наших `RealisticRegion`.
- **Латиница**: используется колонка `Romanized Name` из исходного CSV, а не `Localized Name` — для Японии/Китая/России и т.п. это латинская транслитерация (Aoi, Ruòxī), а не иероглифы/кириллица. Для японского один иероглиф может иметь несколько вариантов чтения — в датасете это отдельные строки, поэтому у Японии больше вариантов, чем уникальных «оригинальных» имён.

## Статус: подключено

Раньше это было staging-данными без подключения — несоответствие эпохи (2010-е имена vs «винтажный» XX век в остальных периодах) решили не смешиванием, а **отдельным периодом «XXI век»** для каждого региона (`{region}_21st_century` в `realisticDataset`, см. [realistic.ts](../datasets/realistic.ts)). Файл `imported-forenames.json` импортируется туда напрямую и служит единственным источником для мужских/женских имён этих периодов — дублирования данных нет.

Оттуда же — эпитеты и титулы для чекбоксов «Include title»/«Include nickname» ([fantasyTitlesAndEpithets.ts](../datasets/fantasyTitlesAndEpithets.ts)); часть неудачных/опечаточных пунктов из исходного списка эпитетов (например, «the Fat», «the Ugly», «the Sadist») отфильтрована вручную. Аналоги для Realistic ([realisticTitlesAndEpithets.ts](../datasets/realisticTitlesAndEpithets.ts)) — не из датасета, подобраны вручную (реальные профессиональные титулы + историческая традиция прозвищ).

## Что осталось не из датасета

У источника нет нейтральных/гендерно-неопределённых имён (только F/M) — для каждого нового периода `neutral` подобран вручную (по 4 имени), не из датасета. Для Западной/Восточной Европы, США, Латинской Америки — уверенность высокая (знакомые культуры). **Для Средней Азии и Индии уверенность ниже** — список отражает моё лучшее приближение (например, Simran/Amrit как пенджабские/сикхские имена, которые действительно используются для обоих полов), стоит перепроверить, если это важно для реального использования.
