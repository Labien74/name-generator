# Импортированные имена (staging, не подключено к приложению)

## Что это

Сырые данные из [sigpwned/popular-names-by-country-dataset](https://github.com/sigpwned/popular-names-by-country-dataset) — популярные имена по странам, источник в основном официальная статистика (данные о рождаемости и т.п.) за разные годы (в основном 2010-е–2018).

- **Лицензия**: CC0 (public domain) — можно использовать без ограничений и без указания авторства.
- **Файл**: [imported-forenames.json](imported-forenames.json)
- **Формат**: `{ [регион]: { F: [{ country, name }], M: [{ country, name }] } }`, регион — один из наших `HistoricalRegion` (`western_europe`, `eastern_europe`, `usa`, `latin_america`).

## Почему это НЕ подключено к `historicalDataset` напрямую

1. **Несоответствие эпохи**: наши существующие периоды `..._20th_century` подобраны вручную под «винтажное» звучание середины XX века (Walter, Harold, Ingrid...). Этот импорт — популярные имена **2010-х годов** (Emma, Liam, Martina...) — звучат современно, а не «XX век». Смешивать напрямую в один период — потерять стилистическую однородность.
2. **Нет нейтральных/гендерно-неопределённых имён** — только F/M, что ожидаемо для статистики по рождаемости.
3. **Разная плотность по странам** — где-то 20 имён на страну, где-то меньше; нужно решить, взвешивать ли по стране или мешать поровну.
